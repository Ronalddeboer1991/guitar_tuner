GUITAR TUNER - install on Android

The app needs an https address once (Android only allows the microphone on secure sites).
After installing, it runs offline and opens instantly.

1. Put these files online, e.g. free with GitHub Pages or Netlify:
   upload ALL files in this folder (index.html, pitch.js, sw.js, manifest.webmanifest, icon-192.png, icon-512.png).
2. Open the address in Chrome on your phone.
3. Chrome menu (three dots) > "Add to Home screen" / "Install app".
4. Allow the microphone the first time.

Tips: hold the phone near the soundhole, pluck one string at a time.
Tap a string button to lock to it; tap again for auto-detect.
